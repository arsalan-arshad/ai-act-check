# Security

This tool fetches public web pages. It must never collect personal data, log in to sites, or store page content beyond what the user asks for.

- Report security issues privately to arsalanarshad.dev@gmail.com. We'll acknowledge within a few days.
- Do not open public issues containing credentials or private URLs.
- Scanning is polite by design: robots.txt respected, rate-limited, identifiable user agent.
